## Build the CV

From the repository root, run:

```bash
latexmk -pdf -interaction=nonstopmode CV_AS.tex
```

Alternatively, if you prefer a direct LaTeX build:

```bash
pdflatex CV_AS.tex
pdflatex CV_AS.tex
```

After compilation, the generated PDF will be available as:

```text
CV_AS.pdf
```
